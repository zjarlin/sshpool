第一个可下载的版本，预发布品质。

## 内容

- 三个平台：`x86_64-unknown-linux-gnu`、`aarch64-apple-darwin`、`x86_64-apple-darwin`
- 每个产物附 `SHA256SUMS` 中的一条摘要
- 一个 `sshpool` 二进制加 `LICENSE`，没有运行时资源文件

## 支持的系统版本

- Linux：glibc ≥ 2.35（Ubuntu 22.04+、Debian 12+、RHEL 9+）。产物在 Ubuntu 22.04 容器里构建，实测最高只引用 `GLIBC_2.34`。
- macOS：Apple Silicon 需 macOS ≥ 11.0；Intel 需 macOS ≥ 10.12（Rosetta 亦可）。
- 运行时依赖：系统 OpenSSH 客户端；Worker 另需 Python 3 与 Docker Linux 引擎。

## 安装

```sh
tar -xzf sshpool-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
install -m 755 sshpool-v0.1.0-x86_64-unknown-linux-gnu/sshpool ~/.local/bin/
sshpool --version   # sshpool 0.1.0
```

从源码构建同样可行：`cargo install --git https://github.com/zjarlin/sshpool --locked`（Rust ≥ 1.89）。

## 这个版本有什么

任务调度器形态的统一 SSH 工作台：一个稳定的 SSH 入口 + 多台隔离构建 Worker，带短期凭据（含独立的 `scrape` 指标凭据）、访问审计、Prometheus 指标、任务状态跨主机副本与离线清理。

## 边界

- 不满足「多台机器合并成一个 Linux 实例」的严格 SSI 要求；跨物理同一进程、Ceph、数据库高可用都没有交付。
- macOS 产物是 ad-hoc 签名，没有公证；首次运行需要自行处理 quarantine 属性。
- 不提供 NAT 穿透，不修改公司既有服务。
