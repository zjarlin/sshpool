# 补充调研评估（2026-11-05）

用户已进一步明确要求严格 SSI。下面的任务调度路线只能描述当前交付物，不再是替代该要求的验收目标。另行核查的 [GiantVM 新内核与 QEMU 路线](ssi-feasibility.md) 更接近未修改客体 OS 的资源汇聚；存在新的 2026 年仓库，不能沿用“只有旧研究项目”的笼统结论。

## 可以采纳的产品判断

当前交付目标是稳定 Linux 工作台、任务调度和隔离构建。普通程序透明共享多节点内存仍是独立研究方向，不能由统一 SSH、容器编排或整项构建分派推导出来。SSHPool 没有集成实验内核。

本次读取了 [Warpgate 仓库](https://github.com/warp-tech/warpgate) 元数据：项目未归档，Apache-2.0 许可，描述明确定位于无额外客户端的透明堡垒机。它适合作为可选身份、授权和录制层；不会自动提供 SSHPool 的工作区或资源调度。当前 SSH 层已复用 OpenSSH，不需要为了单用户原型先引入完整堡垒机。

本次读取了 [tidsOS README](https://github.com/santoputhoor/tidsos)：明确标注 Pre-alpha，列出节点注册、分布式存储两个 MVP 实现，其他方向仍是设计工作。因此记录为观察对象，不列入当前可部署依赖。

sccache/Icecream 是后续编译单元与缓存适配候选；当前仅分派整个命令。Gradle 的开源任务和缓存能力需要与商业 Test Distribution 分开评估。Ray/Dask 并不提供任意普通进程的透明共享内存。

## 需要修正或补来源的说法

- “只有某个研究项目活跃”“没有任何可生产 SSI”属于需要限定检索范围的结论。本次只能确认未找到适合当前异构设备与既有业务的成熟方案；不能用某仓库默认分支更新时间否定整个研究方向。
- “Popcorn 2026 年论文”“Sandlock 启动耗时表”等未附论文链接、硬件、测量口径和样本条件，暂不作为性能指标。应独立复现实验。
- “国内家宽端口映射通常不可行”不能覆盖已有公网 IP 与 DNAT 的环境。可用的局域网直连、端口映射和 frp 都可复用。公开端口被扫描也不是 frp 独有的性质。
- Tailscale/Headscale 可解决部分接入问题，但不能替代资源调度；WSL 网络模式需要按具体系统版本验证。现有 LAN 路由不得被新覆盖网段劫持。
- Landlock 是 Linux 安全机制，能力依内核 ABI 变化。它不是完整容器替代品，也不能直接推断具备完整网络隔离。文件、网络、syscall、资源与进程生命周期需要分别验证；macOS 不适用同一内核机制。

## 对应实现队列

当前 P0：稳定 SSH、数据边界、隔离构建、资源过滤、故障清理、阶段审计、公开交付。

下一阶段 P1：有限期持久队列、快照摘要、更多工具和 WSL 实机验收、sccache profile、可升级配置与保留策略。在线节点启停已经实现并进入验证索引。

后续 P2：数据位置调度、Icecream、测试分片、受控反向接入、外部观测、原生 macOS/GPU Worker。Warpgate 是否纳入取决于是否出现多用户身份需求；Landlock/microVM 是否纳入取决于安全基准。两者不是单用户 MVP 的硬依赖。

所有候选均已落入 `features/*.feature`，状态用证据驱动，未实现能力不会被写成已完成。
